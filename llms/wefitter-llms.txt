# WeFitter

> WeFitter is a health and fitness data platform ("one API to access wearable data, gamification and AI") operated by Thunderbyte.AI in Groningen, Netherlands. It aggregates health and activity data from 300+ wearables and fitness apps (Fitbit, Garmin, Google Fit, Apple Health, Withings, Polar, Oura, Whoop, Samsung Health and more) into a unified REST API, and layers gamification (challenges, leaderboards, teams, points) and AI insights (biological age, recommendations) on top. It is used to build corporate wellbeing, digital fitness, e-health and insurance solutions.

## API

- WeFitter API (REST, Swagger v1.3): https://api.wefitter.com/api/v1.3/
- Base URL: https://api.wefitter.com/api/v1.3
- Authentication: HTTP Basic (client id/secret) is exchanged for a JWT bearer token via POST /token/. Administrator bearer tokens manage profiles/challenges/teams; each profile also has its own profile bearer token returned at creation. Prefix tokens with `bearer `. Admin tokens are valid 24 hours.
